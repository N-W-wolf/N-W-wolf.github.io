## 文档中心包含什么

| 分类 | 内容 | 适合谁 |
| --- | --- | --- |
| 团队与招新 | 团队方向、平台概念、参与方式和常见问题 | 准备加入或刚加入的同学 |
| 入门学习 | 机器人基础知识、工具和阶段性练习建议 | 新成员与自学者 |
| 文档协作 | Markdown 写作、页面排序、Pull Request 流程和示例模板 | 所有文档贡献者 |

## 公开范围

这里是招新与学习用途的公开文档，不承担队内资产管理。以下内容不应写入本站：

- 账号、密钥、个人隐私和内部网络信息。
- 未公开的图纸、采购清单、设备编号和资产台账。
- 未公开竞赛策略、内部配置与详细部署参数。
- 无法确认公开授权的图片、视频或第三方资料。

需要了解团队项目和比赛影像时，请返回[项目主页](/)。
