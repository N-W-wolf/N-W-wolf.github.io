本章面向没有 Linux 使用经验的新成员。第一步先把 Ubuntu 22.04 装到自己的电脑上（与 Windows 组成双系统），之后会陆续补充终端命令、文件系统与权限等基础操作。

## 第一步：安装 Ubuntu 22.04 系统

安装教程：[Ubuntu 22.04 双系统安装（CSDN）](https://blog.csdn.net/hakukun/article/details/147288539)

提示：安装会修改硬盘分区，操作前记得备份重要数据。不同电脑的 BIOS 进入方式和界面可能不同，以开机画面的提示为准。
