开发基础是参与机器人软件开发前需要建立的基本能力，包括操作系统使用、代码版本管理、编程语言基础和网络连接。

## 章节

- [Linux 系统及其操作](/docs/learning/01-development-foundations/linux-system/)：从安装 Ubuntu 22.04 双系统开始，逐步掌握终端、文件系统与权限。
- [Git/GitHub](/docs/learning/01-development-foundations/git-github/)：学习 Git 基础命令、分支、远程推送与 Pull Request 协作流程。
- [Python/C++ 概念](/docs/learning/01-development-foundations/python-cpp/)：了解两种语言的面向对象、编译与解释执行结构，以及 CMake 和 import 等核心概念。
- [计算机网络及 SSH](/docs/learning/01-development-foundations/networking-ssh/)：学习局域网、IP、子网、端口与 TCP/UDP 等基础网络概念，并掌握 SSH 远程连接。

本章不要求系统学习完整的操作系统或编程语言知识，重点是能够进入实际项目环境，运行程序、阅读代码并管理修改。
