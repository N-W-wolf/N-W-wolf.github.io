本章节面向新加入的队员，梳理机械臂涉及的知识体系，并捎带介绍 26 赛季机械臂项目的实现思路。机械臂是入门机器人控制的一个很好的切入对象：它比四足机器人简单，又比小车复杂，涉及的刚体变换、动力学解算与运动规划等基础概念，能为今后更复杂机器人构形的研发打好基础。

内容按三部分组织：

- **概念速览**：先把自由度、串并联构型、运动学/动力学、雅可比矩阵、笛卡尔/关节空间规划等概念串起来，建立整体认知。
- **前备知识**：逐项展开刚体变换、SolidWorks → URDF、正向/逆向运动学、视觉引导感知、轨迹规划、控制基础与电机驱动。
- **项目实现**：26 赛季机械臂的架构总览、运动学引擎、视觉感知管线、控制模式设计、任务编排，以及 MuJoCo 仿真基础。

## 快速上手路线

建议新队员按以下顺序学习：

1. **先跑起来**：`bash run_arm.sh --sim`，体验交互菜单的 15 种操作。
2. **读「刚体变换与矩阵」「SolidWorks → URDF」「正向运动学」「逆向运动学」**：理解 FK/IK/URDF，对照 `arm2.urdf` 和 `kinematics_engine.cpp`。
3. **读「控制基础」**：理解 PD + 前馈，对照 `control_node.cpp`。
4. **读「视觉感知管线」**：理解三阶段管线，在仿真中跑 Case 12 看 Phase 2 对齐过程。
5. **读「视觉引导感知」**：理解视觉引导，对照 `task_node.cpp` 的感知调用和 TF 变换。
6. **读「任务编排」**：理解任务编排，在真机上调试抓取参数。

遇到不懂的概念，回到对应章节查阅推荐资源。
