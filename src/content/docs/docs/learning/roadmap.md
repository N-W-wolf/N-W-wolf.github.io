这份路线用于帮助新成员找到起点，不是固定课程表。根据任务方向选择相关部分即可，不要求一次完成全部内容。

## 第一阶段：建立共同基础

- 学会使用 Git 完成拉取、分支、提交和 Pull Request。
- 能阅读基础 Markdown，并运行仓库中的检查命令。
- 了解坐标系、关节、执行器、传感器和控制周期等基本概念。
- 知道机器人实机测试需要负责人在场，并遵守急停和测试区域要求。

## 第二阶段：选择一个入口

### 机械与硬件

建议学习基础机械制图、常用连接方式、电源与通信接口，并尝试读懂一张简化的整机结构图。

### 控制与仿真

建议复习 Python 或 C++、线性代数和基础控制概念，再通过简单仿真理解观测、动作和反馈之间的关系。

### 软件与部署

建议熟悉 Linux 命令行、进程与日志、版本管理以及基础通信概念，能够说明程序从启动到输出结果的大致流程。

### 测试与资料

建议练习编写测试步骤、成功判据和问题记录，并学习如何压缩图片、整理视频和标注素材来源。

## 第三阶段：完成一个小任务

一个合适的入门任务应满足：

- 一周左右可以完成或得到明确结论。
- 输入、输出和完成标准清楚。
- 不依赖未取得的权限或设备。
- 结果能够用截图、日志、视频或文字说明验证。

## 建议的交付内容

任务结束后至少留下以下信息：

1. 目标和背景。
2. 使用的资料与工具。
3. 实际完成步骤。
4. 结果和验证方式。
5. 尚未解决的问题。

可以直接复制[学习笔记模板](/docs/collaboration/templates/#学习笔记模板)。公开资料只记录可公开的学习过程，不写入队内设备配置和内部参数。
