西安交通大学西北狼战队 RoboCon 四足机器人组围绕四足机器人开展平台设计、仿真训练、运动控制和实机测试。组内平台按足端形式分为点式足与轮足，分别用于不同场景的验证。

## 主要工作

- 机械结构、电气与传感器集成。
- 四足运动控制、仿真训练和策略评估。
- 实机通信、状态反馈与安全测试。
- 场地测试、视频记录和公开资料整理。

主页展示的是公开项目成果。具体任务会随赛季和平台状态调整，新成员不需要在加入前掌握全部方向。

## 适合怎样的同学

- 对机器人、机械、电子、控制或编程感兴趣。
- 愿意从一个范围明确的小任务开始学习。
- 能够记录过程、复现实验并与其他成员协作。
- 遇到问题时愿意先整理现象和已经尝试的方法。

没有机器人项目经验并不影响参与。比起预先掌握某套工具，我们更看重持续投入和完成反馈闭环的能力。

## 加入后可以先做什么

1. 了解点式足与轮足平台的基本差异。
2. 选择机械、电控、控制、仿真或测试中的一个入口。
3. 按[新成员学习路线](/docs/learning/roadmap/)完成基础准备。
4. 在负责人指导下完成一个可验证的小任务。
5. 使用[学习笔记模板](/docs/collaboration/templates/#学习笔记模板)整理过程。
