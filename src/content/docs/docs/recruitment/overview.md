西北狼战队是西安交通大学 ROBOCON 机器人队下属的四足组，主要负责以四足机器人为核心的**软件、算法与控制相关工作**。

组内目前主要采用强化学习技术栈开展四足机器人运动控制，从仿真环境搭建、策略训练与评估，到模型部署、实机通信、参数调试和场地测试，完整参与机器人从算法到实机运行的过程。

这里所说的“软件”并不只是编写程序，而是覆盖机器人控制系统中的多个方向。除了四足机器人的运动控制外，我们还会根据每年的赛题承担其他机器人功能的开发。例如机械臂控制、特殊机构控制，以及为比赛任务服务的定位、导航和任务逻辑等。

虽然每年的具体任务会发生变化，但四足机器人始终是组内最主要的平台，也是学习和技术积累的核心。

机器人的机械结构设计、加工装配以及硬件电路等工作，则主要由 ROBOCON 机器人队中的机械组和硬件组负责。不同机器人在机械、电气等方面具有较强的共通性，因此这些部分由对应专业组统一承担，四足组成员可以更加集中地进行软件、算法和控制方面的开发，同时与机械组、硬件组协作完成整机系统。

## 主要工作

四足组的工作通常包括：

- 四足机器人强化学习运动控制。
- Isaac Gym、Isaac Lab、MuJoCo 等仿真环境的搭建与使用。
- 强化学习策略的训练、评估与优化。
- Sim-to-Real 与模型实机部署。
- 电机通信、状态反馈和机器人底层控制接口开发。
- 实机参数调试、问题定位与运动测试。
- 雷达、相机、IMU 等传感器相关的软件开发。
- 机器人定位、建图与导航。
- 根据赛题开发机械臂或其他机构的控制程序。
- 比赛任务逻辑、系统集成与场地测试。

不同成员不会同时负责所有方向。通常会从一个较明确的任务开始，逐渐了解完整的软件系统，并根据个人兴趣和队伍需求进一步深入某个方向。

主页展示的是目前可以公开的项目成果。具体开发任务会根据赛季、赛题和机器人平台状态进行调整。

## 我们希望你具备的能力

四足组招新主要面向希望参与**软件、算法与控制方向**的同学。

加入前不要求已经掌握强化学习、机器人控制或 ROS 等完整技术栈，但希望你：

- 对机器人、控制、人工智能或编程感兴趣。
- 具备一定的编程基础，并愿意继续学习 C/C++、Python 等工具。
- 愿意学习 Linux，并能够逐步适应机器人开发环境。
- 愿意从一个范围明确的小任务开始，自己查找资料并解决问题。
- 遇到问题时能够说明现象、自己的判断以及已经尝试过的方法。
- 能够持续投入时间完成一个相对完整的任务。
- 愿意与机械组、硬件组以及四足组其他成员协作完成整机开发。

没有机器人项目经历并不会影响参与招新。

相比于提前学过多少框架、使用过多少工具，我们更加关注学习能力、动手能力、解决问题的过程，以及能否持续推进一个任务直到形成结果。

## 假期自学

报名后、正式面试前会安排一段假期自学时间。我们会提供相应的学习方向和参考资料，希望报名同学利用这段时间建立一些最基础的知识，并完成指定的学习内容。<br>自学内容会尽量围绕之后真正需要使用的技术展开，例如：

- Linux 基础使用。
- Git 与基本开发工具。
- C/C++ 或 Python 基础。
- 机器人控制相关基础知识。
- 强化学习的基本概念。
- 仿真平台与机器人开发环境的基本使用。

具体内容可能会根据实际情况进行调整，实际要求以后续的招新资料为准。<br>假期自学并不要求大家提前掌握完整的机器人技术体系，主要是希望所有新成员在进入后续学习期前具备一些共同基础。

## 招新流程

### 1. 报名

填写报名问卷即可参加招新。

报名持续时间通常较长，所有正常填写报名问卷的同学均可以参加之后的面试。

### 2. 假期自学

根据当届发布的学习资料进行自学。

自学内容也是之后技术面试的重要考察范围，因此建议在学习过程中自己实际安装环境、运行程序并完成相应练习，而不是只阅读资料。

### 3. 开学面试

开学后进行面试。

面试阶段原则上不直接淘汰成员，而是进行评分，主要包括两个部分：

**技术考察**

主要围绕假期自学内容进行，考察对基础知识的理解以及实际学习情况。

**能力考察**

如果有参加比赛、科研、项目开发或其他实践活动的经历，会针对具体经历进行交流。

我们更关注你在项目中实际做了什么、遇到了什么问题、如何解决，而不是单纯关注比赛或项目的名称。

### 4. 学习期

面试后进入约三周的学习期。

期间会提供学习方向、参考资料和阶段任务，新成员需要自行完成学习与任务。

学习过程中会持续进行考核和记录，主要关注：

- 学习进度。
- 任务完成情况。
- 对问题的分析过程。
- 实际动手能力。
- 代码与实验结果。
- 沟通与协作情况。

### 5. 队内赛

学习期结束后进行队内赛。

队内赛会布置一个规模更大的综合任务，持续时间也会明显长于学习期任务。

原则上由新成员独立完成，需要经历较完整的：

需求理解 → 方案设计 → 学习与实现 → 调试 → 测试 → 材料整理

最终提交相应材料并进行答辩，根据任务完成情况、实现过程和答辩表现进行评分。

### 6. 最终结算

最终成绩由以下部分按照一定比例综合计算：

- 面试评分。
- 学习期评分。
- 队内赛评分。

根据最终成绩和当届队伍需求，预计招收 **5～6 名**新成员进入四足组。

## 加入之后会做什么

正式加入并不意味着马上开始完成复杂的强化学习算法或整套机器人系统。

通常会根据当时正在进行的项目，从一个具体模块开始，例如：

- 跑通一个强化学习训练环境。
- 修改并验证一个奖励函数。
- 完成机器人与电机之间的通信。
- 将训练好的策略部署到实机。
- 调试一项机器人运动能力。
- 处理雷达或 IMU 数据。
- 完成一个简单的定位或导航任务。
- 为机械臂或其他机构编写控制程序。

随着对系统逐渐熟悉，再进一步接触更加完整的训练、控制和比赛任务。<br>四足机器人涉及强化学习、机器人控制、嵌入式通信、Linux、传感器、定位导航等多个方向，不需要一开始全部掌握。组内更希望新成员能够通过实际项目逐步建立自己的技术体系。
